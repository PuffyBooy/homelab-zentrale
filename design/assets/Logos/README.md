# Logos

Das Zeichen ist ein Rahmen mit einem Bernstein-Quadrat unten rechts: „eine Kiste, die läuft“. Ein echtes Logo gibt es noch nicht. Bis dahin steht neben dem Zeichen der Name „Homelab-Zentrale“ in Space Grotesk 600.

- `hz-mark.svg` ist für dunkle Flächen. Der Rahmen ist `ink` dunkel (#ebe6dc), das Quadrat `accent` (#f5a524).
- `hz-mark-light.svg` ist für helle Flächen, mit dem Rahmen in `ink` hell (#1c1e22).
- Mindestgröße 16 px (Favicon). Ringsum mindestens ein Viertel der Breite frei lassen.
- Das Quadrat bleibt immer Bernstein und wird nie in Statusfarben eingefärbt.
