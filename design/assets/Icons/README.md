# Icons

25 Linien-Icons auf einem 24-px-Raster mit 1,75 Strich und runden Enden. Sie sind identisch mit der `Icon`-Komponente (`window.HZ.Icon`).

- Die SVG-Dateien hier haben die Tinte fest auf `ink-muted` dunkel (#a3a9b2). Im Code nimmst du die `Icon`-Komponente, die über `currentColor` färbt.
- Größen: 14 px in kleinen Buttons, 16 px Standard, 20 px in Kachelköpfen.
- Neue Icons im selben Stil: geschlossene, geometrische Formen, keine Füllungen und kein Detail unter 2 px.
