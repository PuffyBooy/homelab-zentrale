# NavRail

Die Hauptnavigation links mit Tastenkürzeln: 1–9 springen direkt zum Bereich, \` öffnet die Konsole. Am Handy wird sie zur unteren Leiste.

- Reihenfolge: Übersicht, Server, Container, Gameserver, GitHub, Websites, Wohnung, Meldungen, Konsole.
- Der aktive Punkt bekommt eine Bernstein-Tönung.
- Der rote Zähler zählt nur offene Probleme (crit), keine Infos.
