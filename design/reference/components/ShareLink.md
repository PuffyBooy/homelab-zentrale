# ShareLink

Ein Benutzerlink für einen Gameserver: Freunde öffnen ihn ohne Konto und dürfen genau das, was du freigibst.

- Ein Link gehört zu einer Person (`user`) und einem Server. So siehst du, wer was gemacht hat.
- Rechte als Häkchen: Starten/Stoppen, Neustart, Konsole, Whitelist, Dateien. Standard sind nur Starten/Stoppen und Neustart.
- Jeder Link läuft ab (Standard 14 Tage) und kann jederzeit mit „Widerrufen“ (Danger) gesperrt werden.
- Die Seite hinter dem Link zeigt nur diesen einen Gameserver und nichts von deinen anderen Servern.
- Der Link ist ein zufälliges Token und nie eine fortlaufende Nummer.
