# Icon

25 Linien-Icons auf einem 24er-Raster mit 1,75er Strich, die über `color` eingefärbt werden.

- Namen: server, container, git, home, globe, bell, power, terminal, refresh, cpu, thermo, plug, lock, wifi, play, stop, check, alert, door, cloud, gamepad, link, copy, users, plus.
- Standardgröße 16 px in Listen und Buttons, 20 px in Kachelköpfen ist das Maximum. Größer nur im Wandmodus.
- Icons stehen immer neben einem Wort. Ein Button nur mit Icon braucht `aria-label`.
- Farbe kommt aus dem Umfeld (`ink-faint` in Köpfen, `ink-muted` in Buttons). Statusfarben nur in `Alert` und `StatusDot`.
