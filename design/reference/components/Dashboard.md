# Dashboard

Die Übersichtsseite der Homelab-Zentrale, zusammengesetzt aus den Komponenten dieses Systems. Sie ist die Vorlage für die Startseite.

- Oben steht ein Statussatz, der zuerst die Probleme nennt („2 Probleme · 3 von 4 Servern laufen“), rechts der Server-Umschalter.
- Darunter folgen offene `crit`-Meldungen, dann die Server-Leiste über die volle Breite.
- Danach kommen Gameserver und Websites, dann GitHub und Container, jeweils als Paar.
- Die Navigation links hat Tastenkürzel 1–9, und \` öffnet die Konsole.
