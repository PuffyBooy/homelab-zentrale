# ServerSwitch

Ein Umschalter zwischen den Servern. Er filtert jede Seite auf einen Server oder zeigt mit „Alle“ alle nebeneinander.

- Jeder Eintrag: Status, Name (Hostname), Ort.
- Der Zustand des Servers steht immer im Umschalter. So sieht man auch auf einer gefilterten Seite, dass ein anderer Server Probleme hat.
- Bei mehr als 5 Servern wird daraus ein Dropdown.
