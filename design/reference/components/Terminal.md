# Terminal

Konsole und Logs. Sie ist in allen Themes dunkel, weil Logs dunkel gelesen werden und die Farben der Ausgabe so gleich bleiben.

- Kopf: Befehl oder Quelle links, Server rechts.
- Zeilenarten: `cmd` (mit Bernstein-$), `ok`, `warn`, `err`, `dim` für Rauschen.
- Lange Logs scrollen in der Box (`height`). Die Seite selbst scrollt nicht mit.
- Für Live-Konsolen (Web-SSH) zeigt der blinkende Cursor, dass eine Eingabe erwartet wird. Bei reinen Logs `cursor={false}`.
