# GameServer

Die Kachel für einen laufenden Gameserver: Spiel und Version, Adresse zum Kopieren, Spieler online, RAM, TPS und die vier Aktionen Start/Stop, Restart, Konsole und Teilen.

- Die Adresse ist ein Button: Ein Klick kopiert sie, damit man sie schnell an Freunde schicken kann.
- TPS (Ticks pro Sekunde) wird nur bei Spielen angezeigt, die das liefern (Minecraft). 20 ist perfekt.
- Die Namen der Spieler online erscheinen als kleine Tags.
- „Teilen“ öffnet den `ShareLink`, mit dem Freunde den Server selbst steuern können.
- Unten rechts steht immer, auf welchem Server er läuft.
